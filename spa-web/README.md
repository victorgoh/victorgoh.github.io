# Being With Jesus Before Doing for Jesus

> *"I am the vine; you are the branches. If you remain in Me and I in you, you will bear much fruit; apart from Me you can do nothing."* — John 15:5

Welcome! This repository hosts a clean, beautiful, and self-contained single-page reflection application designed to help you slow down, examine your daily rhythms, and choose being with Jesus over doing for Him.

## 🚀 Live Reflection App

You can open and run the interactive reflection app directly in your browser:

### **[👉 Click Here to Open the Live Reflection App](being-with-jesus.html)**

---

## 🌟 Key Features

* **Calming Dual Themes**: Switch between a tranquil twilight mode (*Misty Forest*) and a warm stone mode (*Warm Cream*) depending on your environment.
* **Senior-Friendly Accessibility**: Features a text size toggle (`A` icon) at the top to scale the entire interface for easy reading on mobile screens.
* **Scoreboard-Free Reflection**: Designed strictly as a personal, meditative assessment with no task checklists, counters, or pressure metrics.
* **Auto-Save Progress**: Automatically saves your checked selections and written reflection answers to your browser's local storage so you never lose your place.
* **Formatted Copy & Share**: Copy your summary report in one click, perfectly formatted with clean bullet points and checkmarks, ready to paste directly into your preferred chat or notes app.
* **Save / Print PDF**: Optimized print styles format the worksheet beautifully in black and white when saving as a PDF or printing.
* **100% Offline-Ready**: Runs completely offline as a single HTML file—perfect for saving to your device or sharing as an email attachment.

## 📁 How to Use Locally

If you'd like to download and use this reflection worksheet offline on your own computer or phone:
1. Download the [`being-with-jesus.html`](being-with-jesus.html) file.
2. Double-click the file to open it in any standard web browser (Safari, Chrome, Firefox, Edge).
3. If shared via messaging apps, remember to use the **"Open in Safari"** or browser option rather than viewing it in an in-app preview screen so the scripts can run correctly.
